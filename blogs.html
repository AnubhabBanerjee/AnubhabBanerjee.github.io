I Built a C++ Backend So My GPU Would Stop Eating Air


A tour of WarpGroup-Backend: VRAM-aware bin packing, pinned-memory transfers, and how to cut wasted GPU work when batching variable-length LLM sequences — with code and a few sharp words for default padding. The article treats batching policy as a first-class design choice: padding-to-max length burns cycles on meaningless compute, while dynamic packing under a VRAM budget forces an explicit trade-off between occupancy and tail risk. It traces a path from PyBind11-driven queues through aligned chunking into a FlashAttention-friendly memory contract, using cudaHostAlloc pinned pathways so the GPU sees steady work instead of idle gaps waiting on the host. . . . . Prefill Once, Fan Out: KV Snapshot Sharing for Multi-Agent LLM Pipelines


A systems-engineering approach to KV cache reuse that proves computing a shared prompt once beats N parallel prefills every time. It frames multi-agent and DAG-shaped LLM workloads where each branch would otherwise re-read the same long document into KV at full cost, and explains how copy-on-fork style host snapshots with RoPE-aware continuation can move time-to-first-token off the critical path. The emphasis is on end-to-end measurables—wall clock, prefix reuse, and branch start latency—grounded in a pinned llama.cpp orchestration surface rather than speculative engine features that are not available to call. . . . . Stop trusting the pod status. An end-to-end framework for measuring the hidden microarchitectural costs and memory contention of GPU sharing among AI Agents in Kubernetes. The aim is a receipt-grade account of time-sliced GPUs: when co-scheduled agents collide on memory bandwidth and queueing, what happens to tail latency under load, and which measurement choices expose contention that averages hide. . . . .
