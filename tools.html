VRAM Conductor

Aa C++17 + CUDA orchestrator that lets multiple AI agents share one constrained GPU. A small daemon (`lmxd`) does NVML-seeded admission control to prevent llama.cpp OOM crashes; a layer-streaming engine (PinnedHostPool + LayerStreamer) demonstrates 22–32 % wall-clock savings via double-buffered cudaMemcpyAsync overlap on two CUDA streams, measured on a real PCIe Gen 3 ×16 bus. Ships with a stateless KV-swap helper over `llama.cpp`'s state-serialization API for model-switch eviction. Pure C++17, CMake, llama.cpp pinned to a stable tag.

WarpGroup Backend

A high-performance C++ backend for extreme-context LLM inference. It replaces item-count batching with dynamic, VRAM-aware First-Fit Decreasing (FFD) bin packing. PyBind11 drives async queueing with 16-token alignment, and cudaHostAlloc pinned paths feed zero-copy transfers into FlashAttention-2 — aimed at fewer OOMs and higher sustained GPU throughput.

Annotated LLM Runtime

How to build your own LLM runtime from scratch? Here is the answer. A from-scratch, heavily-annotated CUDA inference runtime for Qwen2.5-Coder-7B on H100 (sm_90). Custom INT4 packer, fused GEMV, paged KV, split-KV attention, CUDA graph decode — every hot path commented for the why. Educational, not a llama.cpp replacement: a learning artifact about owning your own decode stack instead of inheriting one.

SwarmKV

A single-process C++20 inference runtime over llama.cpp for DAG-ordered analytical pipelines: prefill a shared document once, then materialize host KV-cache snapshots for each branch with RoPE-aware sequence offsets. It targets multi-branch workloads where redundant prefix prefill would dominate wall-clock time and time-to-first-token, without relying on an upstream KV bind API that is not exposed on the pinned llama surface.

VLA Edge Backend

A physical AI inference runtime: deadline-aware, memory-bounded inference for streaming Vision-Language-Action (VLA) models on edge GPUs. A hand-written CUDA/C++ transformer (RMSNorm, RoPE, GQA, SwiGLU) runs under a hard 33ms control-loop deadline and an 8GB VRAM ceiling, with lock-free async perception and semantic KV-cache eviction.

Inter-LLM Token Framework

An inter-LLM knowledge handover framework leveraging the Open Knowledge Format (OKF) for the Qwen family. It bypasses text parsing and tokenization by passing binary token arrays directly into model embedding layers via shared memory, for ultra-low latency execution.

ILCP for Agents

Inductive Latent Context Persistence (ILCP) for Agentic AI: infrastructure that persists, routes, and reuses LLM latent context across multi-agent DAGs. By eliminating redundant prefix-prefill compute and optimizing bare-metal VRAM allocation, ILCP drastically lowers tail-latency for parallel agent inference in compute-constrained setups.

Kube Timeslice Profiler

Single-node K3s systems study: measure latency (p50, p95, p99), jitter, and a throughput proxy when a vDU-style FFT workload and a GEMM inference workload share one NVIDIA GPU via the Kubernetes device plugin with CUDA time-slicing. Includes reproducible PyTorch workers, Job manifests, a build/run orchestrator, and a CSV-to-plots pipeline aimed at edge AI-RAN colocation experiments.

CUDA Top-K Retrieval

A CUDA + C++20 testbed for fused similarity and Top-K vector search that keeps a RAG-style retrieval hop on the GPU, avoiding the per-query Python/CPU round-trip that fragments device-side pipelining in agentic loops. CMake builds CUDA kernels, a small C++ orchestrator, and a CPU reference oracle for parity; benchmarks contrast resident on-device search against a host-round-trip baseline.

Kernel Critic

An AI-driven orchestration framework designed to automate the generation and validation of high-performance CUDA kernels. Rather than relying on single-shot LLM prompts, KernelCritic implements a Reflective Agent architecture. It uses a "Critic" node to execute real-time nvcc compilations, feeding hardware constraint failures (e.g., memory coalescing, register pressure) back into the generation loop for automated self-healing.

Shapley value calculator

Shapley value tells us marginal contribution of a player in a cooperative game. During my master's thesis I created a tool to calculate Shapley value of a node in a nettwork. If we consider a graph with weighted nodes and edges, based on the definition of the payoff function, this simulator can calculate the Shapley value of each node of that graph for that payoff function.

Wireless link capacity calculator in urban areas

In semi or dense urban areas, usually there are mutiple floors in each building. We consider box type building distribution (usually found in large cities in the world like Manhattan, Barcelona) and we assume in each building there are multiple floors. During my master's thesis, I developed this tool using which wireless link capacity between any two floor can be calculated. Presenly, in this simulator, only a single street is considered. I have a plan for extending this simulator by considering multiple streets in a whole city.

Greedy graph partitioner

This tool is used to partition a garph following the greedy graph partitioning algorithm proposed in my master's thesis (Please check my publication list to get details about this algorithm). This algorithm partitions a graph into specified number of subgraphs where in each subgraph, all the nodes of that subgraph are within a specified number of hops away.
